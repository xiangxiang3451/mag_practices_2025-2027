# Отзыв научного руководителя о прохождении практики

**Вид практики:** Учебная (ознакомительная) практика, самостоятельная работа в присутствии преподавателя

**Обучающий(ая)ся:** Юрков Андрей Олегович

**Тема практики:** Разработка программы для редактирования учебного плана

Юрков Андрей Олегович в ходе прохождения практики выполнил следующие задачи:

- Изучить существующие утилиты кафедры для работы с учебными планами (постановка задачи, с. 4; раздел 5, с. 5).
- Разработать программное обеспечение для редактирования учебных планов (постановка задачи, с. 4; с. 5–6).
- Дополнительно выявлена задача: написать парсер учебного плана в json-файл для получения данных, уже используемых внутри существующих утилит (с. 5).

В ходе работы обучающийся эпизодически взаимодействовал с руководителем, задачи выполнял преимущественно самостоятельно. По содержанию отчёт описывает выполненную работу: рассмотрены утилиты кафедры, обоснован выбор F#, разработан редактор с экспортом в xslx. Объём текста — 8 страниц, из них содержательная часть составляет около трёх.

К работе имеются следующие замечания:

1. Заявленное не сделано. Задачи 2 и 3 (разработка редактора, экспорт) в отчёте описаны одной фразой: «После чего было разработано приложение для редактирования учебных планов [3]» (с. 5), а экспорт — «был разработан экспорт планов из редактора в xslx формат [3]» (с. 6). Ни архитектуры, ни интерфейса, ни описания пользовательского сценария, ни код listing'ов в отчёте нет.
2. Заключение не подтверждает текст работы. Утверждается, что «были достигнуты все послевоенные цели» (с. 7), при этом разделы 1–4 состоят каждый из одного абзаца, а не из описания результата.
3. Ошибки в тексте, меняющие смысл: «Даля достижение второй задачи требовалось» (с. 5), «разработано возможность экспортирования отредактированных учебных планов» (с. 7). Слово «послевоенные» вместо «поставленные» — очевидная описка, однако в таком виде заключение формально не читается.
4. Нет разделения личного вклада. Выбор языка обоснован «в ходе коллективного обсуждения с Николаем Пономарёвым, вторым разработчиком ПО» (с. 5), при этом в источниках указаны три репозитория, включая `WoWaster/spbu-se-fsharp-plan-editor`, который относится к совместной работе с А. О. Пономарёвым. Какая часть принадлежит автору, из отчёта не следует.
5. Замечание по существу: язык выбран под консистентность с чужими утилитами («не выбивалось бы из общего вида репозитория», с. 5), а не под задачу. Ни в постановке задачи (с. 4), ни в тексте не обосновывается, почему редактор учебного плана вообще должен быть DSL, и чем оказался продукт в итоге.
6. Отсутствуют сведения о продуктовой готовности: ни об интерфейсе, ни о REPL и скриптах .fsx, ни о способе запуска (Docker, Podman, локальная сборка), ни о DataFlow данных. Для редактора учебного плана, который предполагается использовать в работе кафедры, это существенные сведения.
7. Обзор предметной области не выполнен. В тексте нет упоминаний ни действующих систем СПбГУ, ни 1С, ни кафедрального опыта вне контекста репозитория Литвинова.
8. Даты обращения к источникам (с. 8) — 04.01.2025, 05.01.2025, 12.01.2025 — на год раньше даты защиты. Либо даты ошибочны, либо ресурсы не проверялись при написании.
9. Не приложены ни один лист, ни скриншот работы приложения.

**Вывод.** Задачи практики в заявленном объёме не выполнены: отчёт фиксирует факт начала работы и обсуждения выбора инструмента, но не описывает ни архитектуру, ни результат. Зачёт практики в таком виде не рекомендую.

Рекомендую направить на доработку. Прохождение практики по шкале ECTS оценить «C».
